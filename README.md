# Opus Studio

โปรเจกต์นี้มีหน้าแก้ไขแท็กเพลง ตัวแปลงไฟล์ MP4/WebM และเสียงเป็น MP3, Opus หรือ OGG รวมถึง EQ 8 ย่านเสียง

## วิธีเปิดใช้งาน

ต้องมี Node.js 24 ขึ้นไป และ FFmpeg ที่รองรับตัวเข้ารหัส MP3 (libmp3lame), Opus (libopus) และ Vorbis (libvorbis)

```sh
npm run dev
```

จากนั้นเปิด `http://localhost:5000`

ตัวแปลงรับไฟล์ขนาดไม่เกิน 250 MB ไฟล์จะถูกเก็บชั่วคราวระหว่างแปลงและลบเมื่อเสร็จ
